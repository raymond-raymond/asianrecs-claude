# Asian Recs for Claude

Restaurants, desserts, cafes and bars in San Francisco and New York, ranked by how Asian diners rate them
beside how everyone else does. Data from [asianrecs.com](https://asianrecs.com), refreshed weekly.

## Claude Code

```
/plugin marketplace add raymond-raymond/asianrecs-claude
/plugin install asianrecs@asianrecs
```

## Claude.ai and Claude Desktop

Settings → Connectors → Add custom connector → `https://asianrecs.com/api/mcp`

## Try

- "Best soup dumplings in Flushing?"
- "Where do Asian diners like ramen more than everyone else in the East Village?"
- "Boba near 24th and Mission"
